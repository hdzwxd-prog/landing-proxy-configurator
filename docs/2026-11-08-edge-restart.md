# 2026-11-08 意外重启后 Edge 路径异常

现场：GUI Edge 请求为 false，扩展未连接；HKCU 系统代理和 DefaultConnectionSettings 都指向 Wanda 7892；未发现 Edge 代理策略或命令行代理参数。四项 Germany 自启任务 Disabled。
然而 Edge Network Service PID 2388 实际连接 18484，日常浏览器探测得到 NAS04 212.121.132.230。普通命令行通过 7892/7980 均成功。它说明 Edge 实际路径与关闭状态不一致，不能据此判定所有网站均不可达。

重建网络子进程以及发送 WinINET 设置刷新通知均未纠正路径。用户保存网页并明确允许完整重开 Edge。完整重开、恢复标签页后，浏览器实测出口为 Wanda 140.245.46.71；启动 NetLog 的 PROXY_CONFIG_CHANGED 和实际代理解析都为 7892。停止临时 NetLog、再次普通启动后，同样实测通过；连接快照同时观察到普通上游及校内 HTTPS 连接。

Wanda 25376、Clash 24388、常规落地 4260、德国专用核心 16856 全程未重启，系统代理未改。没有启动、断开或访问真实 Claude。原始 NetLog 和会话备份仅保留本机，不提交仓库。

结论：恢复已实测；异常时 Edge 使用旧落地路径已确认，但缺少异常开机时的代理变更记录，不能确定哪个组件何时提供了 18484。完整重开修复当前状态不等于消除重启复发原因。

诊断新增对照：读取 GUI 的只读请求状态；若明确关闭但 Edge 实际连接 18484，必须报路径不一致。GUI 状态未知时不伪报关闭。相应回归测试通过。
